## Gaps Filled This Audit

| Gaps found | Resolved | Escalated |
|---|---|---|
| 2 | 2 | 0 |

Gaps filled 2026-10-09 by the nyquist auditor:

1. **ROADMAP criterion 5, first half** — `imagai generate --help` exiting 0 was only a `<verify>`
   shell command in Plan 01 Task 3, and `POST /api/generate`'s inherited 400 contract existed only
   as a one-off probe in the plan's `<verification>` block. Neither was in the suite. `tests/cli.py`
   even carried a stub named `test_generate_help` that asserted `True`, so a regression would have
   stayed green. Added `test_generate_help_exits_0` (drives the Typer app through `CliRunner`
   offline) and `test_api_generate_contract_unchanged` (Flask test client, `{}` body →
   400 `Prompt is required`).
2. **ROADMAP criterion 6 / SEC-03** — the script-mode proof (`runpy` + stubbed `Flask.run`) lived
   only in Plan 02 Task 1's `<verify>` chain; pytest covered the source ordering but not that the
   script actually reaches `app.run`. Added `test_script_mode_reaches_app_run`, which stubs
   `Flask.run` on the class, asserts the recorded call, and reads the banner from `capsys` —
   no port is bound, so the test behaves identically on a machine where 5000 is occupied.

Post-audit suite: `uv run pytest -k "not llm" -q` → **34 passed, 1 deselected**
(`test_web_server.py` alone: 14 passed).
