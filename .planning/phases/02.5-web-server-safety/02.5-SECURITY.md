## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|----------------|
| HTTP request → argv | `command` field of `POST /api/generate-cli` is caller-controlled; previously handed verbatim to a shell | untrusted string → process spawn (critical) |
| Web page → dev server | any page in the developer's browser can issue a cross-origin POST to `127.0.0.1:5000` | untrusted origin → local HTTP API |
| Request → output directory | `generated_images` was built by scanning a directory shared with every concurrent caller | other requests' file names + base64 payloads |
| Process start → module execution | running the file as a script executes the `__main__` guard at module scope | module body → `NameError` (availability) |
| Network → listening socket | `app.run(host=..., debug=...)` decides interface reachability and debugger attachment | remote code execution / info disclosure |
| Package index → project environment | `pyproject.toml` → `uv.lock` → `.venv` supply chain | declared vs. actually-installed packages |
| Documentation → operator belief | a doc claim reinvests a removed posture with authority | stale claim → operator accepts old threat model |
