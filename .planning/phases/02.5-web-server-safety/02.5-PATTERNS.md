#### Error-response contract (Phase 2 D-04 — load-bearing)

The whole file speaks one dialect: `return jsonify({...}), <status>` — a **populated body, never a raised exception**. Every handler wraps its body in `try/except Exception`.

Validation rejection, `web_server.py:83-84`:


Validation rejection with context, `web_server.py:101-104`:
```python

        jsonify({"success": False, "error": f'Engine "{engine}" is not configured'}),
        400,

```

Unexpected-exception terminal handler, `web_server.py:221-224`:
```python
except Exception as e:
    return jsonify(
        {"success": False, "error": str(e), "type": type(e).__name__}
    ), 500
```

**Apply to:** the rewritten `/api/generate-cli`. Keep the same three-tier shape — specific rejection (400) → domain failure (500) → outer catch-all (500) — and never let a `shlex.split` `ValueError` escape as a 500-by-accident instead of a populated 4xx. CONTEXT leaves the 400-vs-500 choice for `shlex` failures to agent discretion; the constraint is only *"populated error body, never a raised exception."*

#### `main()` definition order + defaults (D-05, D-06)

`web_server.py:364-377` currently:
```python

    main()


def main(
    host: str = "0.0.0.0", port: int = 5000, debug: bool = True, threaded: bool = True
):
    print("🎨 Starting Imagai Web Server...")
    ...
    app.run(host=host, port=port, debug=debug, threaded=threaded)
```

**Defect:** `main()` is defined *after* the guard, so `python src/imagai/web_server.py` raises `NameError`. Fix is a pure move — `def main(...)` block goes **above** `if __name__ == "__main__":`, and the guard stays last in the file.

**Defaults flip (D-06):** `host: str = "0.0.0.0"` → `"127.0.0.1"`; `debug: bool = True` → `False`. Leave `port=5000`, `threaded=True` alone.

Placement: `main()` belongs after the two `@app.errorhandler` blocks at `:354-361` — that keeps every route + handler definition above both `main()` and the guard, mirroring the file's existing top-down order.

Entry point that must keep working — `pyproject.toml:38`: `imagai-web = "imagai.web_server:main"`. The `main` symbol must remain module-level and callable with zero args.

#### **Mocking `subprocess.run` — patch target matters**

Mandatory per `.planning/codebase/TESTING.md:554`: *"Do not write a test that exercises `generate-cli` against a real shell."*

`web_server.py:10` does `import subprocess` and `:248` calls `subprocess.run(...)` — it binds the **module**, not the name. So `imagai.web_server.run` does not exist and patching it fails with `AttributeError`. The correct target is:
```python
with patch.object(web_server.subprocess, "run", return_value=fake_result) as m:
    ...
```
equivalently `patch("imagai.web_server.subprocess.run")`. Flag this explicitly in the plan — it is the single most likely way a generated test silently hits a real shell.

The fake must carry all four attributes the response builder reads (`:257-263`):
```python
from types import SimpleNamespace
fake = SimpleNamespace(returncode=0, stdout="", stderr="")
```

Also assert the *shape* of what was passed, which is how the `shell=False` regression is proven without a shell:
```python
args, kwargs = m.call_args
assert args[0] == ["imagai", "generate", "-p", "a cat"]   # token list, not a string
assert kwargs["shell"] is False
```

#### Patching `UPLOAD_FOLDER` for the D-04 diff test (trap)

`web_server.py:33` — `UPLOAD_FOLDER = Path(settings.output_dir)` is captured **once at import time**. Patching `settings.output_dir` alone will *not* move the directory the endpoint scans. Patch both, so the test is correct regardless of which the implementation reads:
```python
with tempfile.TemporaryDirectory() as tmpdir:
    out = Path(tmpdir) / "out"
    out.mkdir()
    with patch.object(web_server, "UPLOAD_FOLDER", out), \
         patch.object(settings, "output_dir", str(out)):
        ...
```
Sequence for the leak test: create a pre-existing `old.png` in `out`, `POST /api/generate-cli` with `subprocess.run` mocked by a side effect that writes `new_1.png` + `new_2.png` into `out` (this also proves the N-variant batch capture of D-04), then assert `old.png` **not** in the response filenames and `new_1.png`/`new_2.png` **are**.
