# Phase 02.5 Plan 02: Web Server Safety Summary

**`main()` now sits above the `__main__` guard with `host="127.0.0.1"` / `debug=False` defaults, and the wide-open `CORS(app)` grant is gone**

## Accomplishments

- `python src/imagai/web_server.py` starts. The `def main(...)` block moved above the `if __name__ == "__main__":` guard (a pure move — body, print lines, and the `app.run` call untouched), so the script no longer raises `NameError: name 'main' is not defined`. Placement is after the two `@app.errorhandler` blocks, keeping every route and handler above both `main()` and the guard.
- A bare `imagai-web` is loopback-only with the debugger off: `host: str = "0.0.0.0"` → `"127.0.0.1"`, `debug: bool = True` → `False`. `port=5000` and `threaded=True` are unchanged — neither is a security concern here. Both flipped parameters stay overridable by explicit argument; the fix is a default, not a lock.
- The drive-by path is closed. `from flask_cors import CORS` and `CORS(app)  # Enable CORS for all routes` are deleted with no substitution, leaving the import block as flask + werkzeug. `GET /` serves `web_interface.html` same-origin and that page calls only `/api/generate` and `/api/engines` (verified by grep — it never called `/api/generate-cli`), so the bundled UI needed no grant.
- A real start-and-kill run confirmed the posture end to end: the banner printed, then `* Running on http://127.0.0.1:5000` and `* Debug mode: off`.

## Decisions Made

- **`flask-cors` stays declared in `pyproject.toml`.** Removing the import while the dependency is still declared is the correct intermediate state. The `pyproject.toml` → `uv.lock` → `uv sync` chain moves in one step in Plan 02.5-03; splitting it here would be two commits for one logical change. A declared-but-unused package cannot be reached, so it cannot be a vulnerability — this mirrors the plan's own T-025-09 disposition ("accept", low).
- **The defaults live in the signature, not in the body.** `debug` is not hard-pinned to `False` inside `main()` and the `host` parameter is not deleted, so a deliberate shared-interface run can still ask for `host="0.0.0.0"`. Plan text is explicit: "the fix is a default, not a lock."
- **The SEC-07 tests assert on headers, never on status.** `resp.headers.get("Access-Control-Allow-Origin") is None` holds whether the endpoint returns 400 (allow-list rejection) or 200, so the assertion cannot be satisfied or broken by a change to the request-handling logic.

- **Port 5000 was free, contrary to the plan's prediction.** The plan states that a literal `python src/imagai/web_server.py` bind fails with `OSError: [Errno 48] Address already in use` because macOS ControlCenter holds `*:5000`, and that the banner-only probe "echoes success with no socket ever bound". On this machine the port was clear, so the real process bound and served normally — exit status 143 (SIGTERM) after the kill, no `NameError`, and the live output shows `* Running on http://127.0.0.1:5000` and `* Debug mode: off`. This is stronger evidence than either probe predicted; the runpy probe (which stubs `Flask.run`) was still run and is machine-independent by design.
